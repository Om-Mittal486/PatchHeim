## PatchHeim
> **Theme:** Multiverse is Breaking
> **Developed during:** Summer Vacation First Year

PatchHeim is a 2D top-down rpg game developed for learning purposes. In this game I have tried to implement some of the SOLID principles and Design Patterns.

## About the Game

Nomad - The Uncertain Route is a Top-Down 2D RPG developed during the my first year summer vacation, where our main character is on a journey to fix some some glitches occuring in the multiverse. This game is not complete and is just for my practice and learning game design patterns and SOLID principles.

## Get Started (Local Setup)

### Clone the Repository

```bash
git clone https://github.com/Om-Mittal486/PatchHeim.git
```

### Open in Unity

1. Launch Unity Hub
2. Click Open Project
3. Select the cloned project folder

### Build and Run

- Open the project in Unity
- Press Play in the Unity Editor, or
- Build the game using Unity’s build system
